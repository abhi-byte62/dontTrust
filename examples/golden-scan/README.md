# DontTrust Golden Scan Example

This directory contains deterministic, sanitized benchmark scan outputs generated by running DontTrust against the controlled local lab target (`lab/vulnerable-app`).

## Contents

- `scan-result.json`: Full canonical scan record containing target metadata, execution duration, discovered endpoints, and verified findings.
- `findings.json`: Canonical findings array with severity, confidence, differential verification status, and sanitized HTTP/DOM evidence.
- `attack-surface.json`: Attack-Surface Graph nodes and edges representing domains, routes, endpoints, parameters, and technologies.
- `report.md`: Markdown assessment report with executive summary, methodology, finding breakdown, and remediation advice.
- `results.sarif`: OASIS SARIF v2.1.0 formatted vulnerability output for CI/CD ingestion.
